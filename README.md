# Лабораторные работы по цифровой обработке сигналов

**Автор:** Тарасенко К.А.  
**Вариант:** БПФ_Ч (БПФ с прореживанием по частоте)

## Описание

Данный проект содержит две лабораторные работы по цифровой обработке сигналов:

### Лабораторная работа 1: Свертка, корреляция и преобразование Фурье
- Генерация периодических музыкальных сигналов
- Реализация операций свертки и корреляции (собственная и через БПФ)
- Прямое и обратное БПФ с прореживанием по частоте
- Построение амплитудных и фазовых спектров
- Анализ эффективности алгоритмов при разных значениях N

### Лабораторная работа 2: Цифровые фильтры
- Реализация однородного фильтра
- КИХ высокочастотный фильтр с окном Блэкмана
- БИХ низкочастотный однополюсный фильтр
- Анализ эффективности фильтров
- Построение АЧХ и временных характеристик

## Запуск

### Основной способ (рекомендуется)

```bash
python3 main.py
```

Откроется интерактивное меню с опциями:
1. Запустить Лабораторную работу 1
2. Запустить Лабораторную работу 2  
3. Запустить обе лабораторные работы
4. Очистить результаты
5. Показать структуру файлов
0. Выход

### Запуск отдельных лабораторных работ

```bash
# Только лабораторная работа 1
python3 laba1_runner.py

# Только лабораторная работа 2  
python3 laba2_runner.py
```

## Результаты

Все результаты сохраняются в структурированном виде:

### Аудиофайлы (`static/audio/`)
- `periodic_signal_1.wav`, `periodic_signal_2.wav` - исходные сигналы
- `signals_after_convolution.wav` - результат свертки
- `signals_after_correlation.wav` - результат корреляции
- `laba2_distorted_signal.wav` - искаженный сигнал
- `laba2_*_filtered.wav` - отфильтрованные сигналы

### Графики (`static/plots/`)
- `laba1_*_spectrum.png` - амплитудные и фазовые спектры
- `laba1_*_time.png` - временные графики сигналов
- `laba1_algorithm_efficiency.png` - сравнение эффективности алгоритмов
- `laba2_*_signal.png` - временные графики фильтрованных сигналов
- `laba2_*_spectrum.png` - спектры фильтрованных сигналов
- `laba2_*_frequency_response.png` - АЧХ фильтров

## Особенности реализации

### Лабораторная работа 1
- **БПФ с прореживанием по частоте** - собственная реализация алгоритма
- **Свертка и корреляция** - как прямые алгоритмы, так и через БПФ
- **Сравнение эффективности** - анализ временной сложности O(N²) vs O(N log N)
- **Проверка корректности** - сравнение собственных реализаций с библиотечными

### Лабораторная работа 2
- **Однородный фильтр** - простое масштабирование сигнала
- **КИХ ВЧ-фильтр** - с окном Блэкмана, настраиваемый порядок
- **БИХ НЧ-фильтр** - однополюсный, экспоненциальное сглаживание
- **Анализ эффективности** - SNR, подавление шума, сохранение сигнала

## Преимущества новой структуры

1. **Централизованное управление файлами** - все результаты в одном месте
2. **Модульность** - переиспользование кода между лабораторными работами
3. **Удобный интерфейс** - интерактивное меню для запуска
4. **Структурированность** - четкое разделение по типам файлов
5. **Расширяемость** - легко добавить новые лабораторные работы
