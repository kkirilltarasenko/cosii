# Быстрый старт

## Запуск лабораторных работ

### 1. Основной способ (интерактивное меню)
```bash
python3 main.py
```

### 2. Запуск отдельных лабораторных работ
```bash
# Лабораторная работа 1 (Свертка, корреляция, БПФ)
python3 laba1_runner.py

# Лабораторная работа 2 (Фильтры)
python3 laba2_runner.py
```

## Структура результатов

После выполнения лабораторных работ все файлы будут сохранены в папке `static/`:

```
static/
├── audio/          # Аудиофайлы (.wav)
├── plots/          # Графики (.png)
├── data/           # Данные
└── archive/        # Старые файлы
```

## Что делает каждая лабораторная работа

### Лабораторная работа 1
- ✅ Генерирует 2 периодических сигнала
- ✅ Выполняет свертку и корреляцию
- ✅ Строит спектры и временные графики
- ✅ Сравнивает эффективность алгоритмов
- ✅ Проверяет корректность через БПФ

### Лабораторная работа 2
- ✅ Создает искаженный сигнал
- ✅ Применяет 3 типа фильтров
- ✅ Строит АЧХ фильтров
- ✅ Анализирует эффективность фильтрации
- ✅ Сравнивает результаты
