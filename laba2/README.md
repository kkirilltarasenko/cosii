## Реализованные фильтры

### 1. Однородный фильтр
- **Тип:** Простое масштабирование
- **Параметры:** Коэффициент усиления (gain = 0.5)
- **Применение:** Ослабление общего уровня сигнала

### 2. FIR высокочастотный фильтр
- **Тип:** КИХ-фильтр с конечной импульсной характеристикой
- **Окно:** Блэкмана
- **Частота среза:** 1000 Гц
- **Порядок фильтра:** 51
- **Применение:** Подавление низкочастотных компонент

### 3. IIR низкочастотный фильтр
- **Тип:** БИХ-фильтр с бесконечной импульсной характеристикой
- **Структура:** Однополюсный
- **Частота среза:** 2000 Гц
- **Применение:** Подавление высокочастотных компонент

## Математические основы

### Окно Блэкмана
```
w(n) = 0.42 - 0.5*cos(2πn/(N-1)) + 0.08*cos(4πn/(N-1))
```

### FIR высокочастотный фильтр
Импульсная характеристика:
```
h(n) = δ(n) - h_lp(n)
```
где h_lp(n) - импульсная характеристика НЧ-фильтра

### IIR однополюсный фильтр
Разностное уравнение:
```
y[n] = b₀*x[n] - a₁*y[n-1]
```
где коэффициенты вычисляются через билинейное преобразование

## Экспериментальная проверка

## Теоретические основы

### Окно Блэкмана
Окно Блэкмана обеспечивает хорошее подавление боковых лепестков (-57 дБ) при умеренном расширении главного лепестка. Это делает его подходящим для приложений, где важно минимизировать спектральную утечку.

### Билинейное преобразование
Для проектирования IIR фильтра используется билинейное преобразование:
```
s = (2/T) * (z-1)/(z+1)
```
где T - период дискретизации.

### Частотная характеристика
Частотная характеристика цифрового фильтра:
```
H(e^jω) = Σ h(n) * e^(-jωn)
```
